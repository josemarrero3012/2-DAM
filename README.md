# 2.º de DAM

Mis apuntes y prácticas de clase de segundo de Desarrollo de Aplicaciones Multiplataforma, ordenados por módulo y por tema.

- **PGL:** apps para Android con Kotlin.
- **DAD:** programas en C# con .NET, de consola, con Windows Forms y con WPF.
- **AED:** ejercicios en Java.

Las apps de Android se abren con Android Studio, los proyectos de C# con Visual Studio y los de Java con IntelliJ IDEA.
